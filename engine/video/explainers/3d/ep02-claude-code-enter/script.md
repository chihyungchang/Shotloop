# 02 · Script

Step 2. No voice-over; ≤ 12 words up at once. 100 bpm, one bar = 2.4 s,
20 bars = 48 s. Captions sit on a dark panel in the top band (y 110–
520) so they read over a bright sky too.

| Bar | Time | Place | On screen |
| --- | --- | --- | --- |
| 1 | 0.0–2.4 | Room | You press **Enter** in Claude Code. |
| 2–3 | 2.4–7.2 | Room → router | Your prompt and its context leave as one request. *the chat so far · instructions · tools · files it read · over HTTPS* |
| 4–5 | 7.2–12.0 | Street → provider | Out through your internet provider… |
| 6–8 | 12.0–19.2 | Seabed | …and across an ocean, in a cable on the seabed. *Almost all data between continents travels this way. (TeleGeography)* |
| 9–10 | 19.2–24.0 | Data centre | To a data centre, possibly an ocean away. |
| 11 | 24.0–26.4 | Chip | Chips like GPUs and TPUs run the model. |
| 12–13 | 26.4–31.2 | Model | Layer by layer, it works out the next token. *(illustration)* |
| 14 | 31.2–33.6 | Seabed | Each token comes back the same way, streamed. |
| 15–16 | 33.6–38.4 | Room | Sometimes the reply is a request: read a file, run a command. *You approve; it runs on your machine; the result goes back.* |
| 17–19 | 38.4–45.6 | Overview | Again and again, until it's done. **That loop is the agent.** |
| 20 | 45.6–48.0 | Overview | Sources · oliverz.dev |

Illustrative: the route (one provider, one cable, one data centre), the
model as stacked layers, and the screen text (`explain how auth works
here`, `Read(src/app.ts)`).
