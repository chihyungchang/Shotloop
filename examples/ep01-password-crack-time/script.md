# 01 · Script

Step 2: the words on screen, timed. There is no voice-over: the text is
the narration, so every line has to read in the time it is up (about
3 words a second, never more than ~12 words at once).

100 bpm → one bar is 2.4 s. Every cut lands on a bar line, so the music
(music.json) hits on it. Total 16 bars = 38.4 s.

| Bar | Time | On screen |
| --- | --- | --- |
| 1 | 0.0–2.4 | How long would a hacker need to crack **your** password? |
| 2–3 | 2.4–7.2 | Their rig: **16 × RTX 5090** GPUs, guessing nonstop. |
| 4–5 | 7.2–12.0 | 8 random characters, lowercase only… → **≈ 2 weeks** |
| 6–7 | 12.0–16.8 | Now mix UPPER, lower, numbers, symbols… → **132 years** |
| 8–9 | 16.8–21.6 | Safe? It keeps falling. 2024: 225 yrs · 2025: 164 · 2026: 132. **20–25% faster every year.** |
| 10–11 | 21.6–26.4 | But that's for a **random** password nobody has ever seen. Reused? Leaked? A real word? |
| 12–13 | 26.4–31.2 | **Cracked almost instantly.** Attackers try leaked passwords first. |
| 14–15 | 31.2–36.0 | What works: long + random (password manager) · never reuse · turn on 2FA |
| 16 | 36.0–38.4 | Source: Hive Systems 2026 Password Table |

Example passwords shown as "leaked" in bars 12–13 are illustrative
(password123, summer2024!, qwerty), not taken from a real breach list,
and carry no crack-time number.
