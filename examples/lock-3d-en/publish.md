# How does a key open a pin tumbler lock? · Publish

## YouTube Shorts

Title:

```
How a key opens a pin tumbler lock
```

Description:

```
Why does only one key turn this lock? Inside, springs push stacks of pins down across the gap between the turning plug and the fixed housing, so the inner cylinder can't turn.

Slide the key in, and each ridge lifts its pin stack to a different height. With the right key, every split between key pin and driver pin lines up exactly on that gap, the shear line.

Nothing blocks it now, so the plug turns and works the bolt through a cam. One key, one exact pattern.
```
