# How does a key open a pin tumbler lock · Script

1. Why does only one key turn this lock?
2. Inside, springs push stacks of pins down across the gap, so the inner cylinder can't turn.
3. Slide the key in, and each ridge lifts its pin stack to a different height.
4. With the right key, every split between pins lines up exactly at the gap.
5. Nothing blocks it now, so the cylinder turns and the bolt slides back.
6. One key, one exact pattern.
