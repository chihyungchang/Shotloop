# How does a key open a pin tumbler lock

## Idea

A pin tumbler lock is blocked by stacks of spring-loaded pins that cross the gap between the turning plug and the fixed housing; the right key lifts every stack so its split sits exactly on that gap, the shear line, and the plug can turn.

## Hook

Why does only one key turn this lock?

## Copy

Why does only one key turn this lock?

Inside, springs push stacks of pins down across the gap, so the inner cylinder can't turn.

Slide the key in, and each ridge lifts its pin stack to a different height.

With the right key, every split between pins lines up exactly at the gap.

Nothing blocks it now, so the cylinder turns and the bolt slides back.

One key, one exact pattern.

## Facts

- A pin tumbler lock has a plug (inner cylinder) inside a housing, with stacks of key pins and driver pins pushed down by springs across the gap between them. (source: Wikipedia, Pin tumbler lock, https://en.wikipedia.org/wiki/Pin_tumbler_lock)
- Without the right key, the driver pins sit across the gap and stop the plug from turning. (source: Wikipedia, Pin tumbler lock, https://en.wikipedia.org/wiki/Pin_tumbler_lock)
- The cuts of the correct key raise each pin stack so the split between key pin and driver pin aligns with the shear line, letting the plug rotate and work the bolt through a cam. (source: Wikipedia, Pin tumbler lock, https://en.wikipedia.org/wiki/Pin_tumbler_lock)
