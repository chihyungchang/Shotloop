# 每天进步 1%，一年后是多少？

## Idea

把「每天进步 1%」这句鸡汤算一遍：1.01 连乘 365 次，和 0.99 连乘 365 次，差距有多大？
再诚实地补一句：现实里的进步不是恒定的 1%，真正在复利的是每天坚持的小习惯。
16:9 横屏，约 26 秒，纸张底色、深绿（增长）和暗红（衰减）两种颜色。

## Facts

All computed from the formula below (double precision, rounded for display).

- 1.01^365 = 37.7834 → 显示「≈ 37.78」
- 0.99^365 = 0.025518 → 显示「≈ 0.026」（约起点的 2.6%）；差距公式里写作 0.0255
- 1.01^365 ÷ 0.99^365 = (1.01 / 0.99)^365 = 1,480.66 → 显示「≈ 1,481 倍」
- 1.01^70 = 2.007 → 「第 70 天，翻了一倍」
- 0.99^69 = 0.4998 → 「第 69 天，只剩一半」
- 1.01 与 0.99 每天只差 0.02
- 05-habits 的打卡日历是示意图（固定种子生成），不是真实数据

## Sources

- Formula: value after n days = (1 ± 0.01)^n, n = 365. Check with
  `node -e "console.log(1.01**365, 0.99**365, (1.01/0.99)**365)"`.
